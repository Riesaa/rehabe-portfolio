# Rehabe Essabaouni — Portfolio

Portfolio React + TypeScript + Tailwind CSS + Vite.

## Installation

```bash
npm install
npm run dev
```

Puis ouvre l'URL affichée par Vite.

## Production

```bash
npm run build
npm run preview
```

## Personnalisation

- Les projets et expériences sont dans `src/main.tsx`.
- Le CV est dans `public/CV-Essabaouni-Rehabe-updated(1).pdf`.
- Les styles globaux sont dans `src/index.css`.
